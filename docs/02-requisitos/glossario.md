# Glossário

Termos do domínio usados em todo o código e documentação. Mantenha sempre em PT-BR
no produto; nomes técnicos (tabelas, enums) seguem este glossário em inglês.

| Termo (pt) | Termo técnico | Significado |
|---|---|---|
| Vitrine | `storefront` | Área pública de navegação/compra de produtos. |
| Artesão / Produtor | `artisan` | Usuário vendedor cadastrado e aprovado. |
| Comprador | `buyer` | Usuário que compra. |
| Administrador | `admin` | Equipe da plataforma com papel administrativo. |
| Produto / Peça | `product` | Unidade vendável pertencente a um artesão. |
| Origem | `origin` | Local/região/cidade de onde vem a peça (ex.: Caruaru). |
| Técnica | `technique` | Processo artesanal empregado (cerâmica, renda, xilogravura...). |
| Categoria | `category` | Agrupamento de produtos (nível máximo controle de escopo). |
| Estoque | `stock` | Quantidade disponível de um produto. |
| Pedido | `order` | Compra única; pode ter itens de vários artesãos. |
| Item de pedido | `order_item` | Linha do pedido ligada a um produto de um artesão. |
| Carninho | `cart` | Lista temporária de itens antes do checkout. |
| Avaliação | `review` | Nota 1–5 + comentário, pós-entrega, com moderação. |
| Pagamento simulado | `simulated payment` | Fluxo fake de confirmação de pagamento, sem gateway real. |
| Recomendação | `recommendation` | Módulo que sugere produtos similares/relevantes. |
| Indicadores | `indicators/dashboard` | Agregados de venda (faturamento, top N, ticket médio). |
| Página de produto | `product page` | Detalhe público de uma peça. |
| Perfil público | `artisan profile` | Página de apresentação do artesão. |
